ClearSky File Naming Convention

All files follow a structured naming pattern for SharePoint compatibility.
The Librarian auto-detects and renames files to match these rules.

        │     └── MA_{Company}_{Project}_{Year}.pdf

Rules

1. No spaces in filenames — use underscores
2. Company names use CamelCase with underscores for spaces
3. All dates in filenames use YYYY format
4. Extensions preserved from original (.pdf, .docx, .xlsx)
5. Executed/signed versions get _EXECUTED suffix
6. Draft versions get _DRAFT suffix
7. Redline versions get _REDLINE suffix
